ⓘ System Formulation
Generalized Examination Timetabling Platform: Designed for university scheduling with multi-campus venue allocation, travel distance constraints (Drp), course coincidence synchronization, and student clash minimization (closely matching the UMP benchmark dataset environment).

📂 Custom Dataset Upload & 7-File Checklist

Upload your institution files (CSV or Tab-delimited TXT). The system dynamically allocates variable courses, students, and venues.

Expected File Formats (Comma or Tab Delimited):

1. Campus File (campus.txt)        : subject, campus                  (e.g. G0001 G | P0001 P)
2. Coincidence (coincidence.txt)   : subject1, subject2              (e.g. G0002 P0002 | G0004 P0004)
3. Course File (course.txt)        : subject, total of student        (e.g. G0001 710 | G0002 689)
4. Distance Matrix (distance.txt)  : room1, room2, distance matrix  (e.g. DBP DBP 0 | VBK02 VDK01 3)
5. Room Info (roominfo.txt)        : block, campus, capacity, room    (e.g. D G 1019 DBP | A G 355 ASTAKA)
6. Student File (student.txt)      : student id, subject              (e.g. PB15124 G0004 | PB16022 G0009)
7. Timeslot File (timeslot.txt)    : subject, timetaken for exam      (e.g. G0001 90 | G0003 180)
